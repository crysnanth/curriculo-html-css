# Portfólio Pessoal — HTML5 e CSS3

**Autor:** Crysnanth

## Descrição

Portfólio acadêmico para praticar fundamentos de desenvolvimento web com páginas estáticas, HTML semântico e estilos responsivos. Substitua os campos entre colchetes e o nome de exemplo por suas informações antes de publicar.

## Tecnologias

- HTML5
- CSS3

## Páginas

- `index.html`: apresentação, interesses e atalhos para o conteúdo.
- `curriculo.html`: perfil acadêmico editável, formação, habilidades em aprendizado e projeto acadêmico.
- `blog.html`: artigo introdutório sobre Flexbox e CSS Grid, com índice, tabela, exemplos e referências.
- `fotos.html`: galeria em CSS Grid com ilustrações placeholder locais.
- `contato.html`: formulário demonstrativo sem envio de dados.

## Funcionalidades

- Navegação entre as cinco páginas, indicação da página atual e links para voltar ao topo.
- Layout responsivo com CSS Grid, Flexbox e media queries.
- Galeria com legendas e textos alternativos.
- Artigo técnico com âncoras internas e links para a MDN.
- Formulário marcado como demonstrativo; não envia nem armazena informações.

## Como executar

Abra `index.html` diretamente em um navegador e navegue pelo menu. Não é necessário instalar pacotes ou iniciar um servidor.

## Créditos e imagens

As ilustrações SVG em `imagens/` foram criadas localmente para este projeto como placeholders visuais. Não são fotografias nem imagens externas. Substitua-as por arquivos próprios ou licenciados se desejar uma galeria fotográfica e documente autor, fonte e licença aqui. O diagrama Flexbox/Grid também é uma ilustração vetorial local criada para este projeto. O artigo aponta para documentação pública da MDN; nenhum vídeo externo foi incorporado.
